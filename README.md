# ⏰ Digital Clock

A simple and stylish digital clock built using **HTML, CSS, and JavaScript**.

The clock displays the current time and date in real-time with a green glowing interface.

## ✨ Features

- 🕒 Displays current time
- 📅 Displays current date
- 🔄 Automatically updates every second
- 🌙 Dark background
- 💚 Green glow effect
- 📱 Simple and lightweight design
- ⚡ Built with pure HTML, CSS and JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Digital-Clock/
│
├── index.html
├── style.css
├── script.js
└── README.md
````

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Sakshamhanda/Digital-Clock.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! The clock will start automatically.

## 📌 How It Works

JavaScript uses the `Date()` object to get the current system time and date.

The clock is updated every second using:

```javascript
setInterval(updateTime, 1000);
```
